# Invoice Generation Web Application

A full-stack MERN Invoice Generation Web Application that allows users to create, manage, preview, and export professional invoices with real-time calculations and dashboard analytics.

---

## 🚀 Features

### Invoice Management
- Create professional invoices
- Auto-generated invoice numbers
- Add multiple dynamic line items
- Tax calculations
- Discount calculations
- Invoice notes & payment terms
- Invoice status system:
  - Draft
  - Pending
  - Paid
  - Overdue

### Invoice Operations
- Save invoices to MongoDB Atlas
- Load saved invoices
- Update invoices
- Delete invoices
- Search invoices by invoice number or client name

### Preview & Export
- Real-time invoice preview
- PDF export / print support
- Invoice status visible in PDF

### Dashboard Analytics
- Total invoices
- Total revenue
- Average invoice value
- Monthly invoice statistics

### UI / UX
- Responsive mobile-friendly design
- Professional SaaS-style UI
- Toast notifications
- Form validation
- Error handling
